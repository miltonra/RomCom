
Python References
-------------------

The coding paradigm and style of RomCom borrows heavily from three essential references

* `The Python Standard Library <https://docs.python.org/3/library/>`_ by the Python Software Foundation.
* `The Lizard Book <https://www.fluentpython.com/>`_ by Luciano Ramalho.
* `Effective Python <https://effectivepython.com/>`_ by Brett Slatkin.

Extensive use is made of the following third-party Python libraries

* `pandas <https://pandas.pydata.org/>`_ for data storage and manipulation.
* `numpy <https://numpy.org/>`_ for numerical computations.
* `torch <https://pytorch.org/>`_ for tensor computations.
* `scipy <https://www.scipy.org/>`_ for miscellaneous scientific computations.
* `SALib <https://salib.readthedocs.io/en/latest/index.html>`_.

and, of course, the common language which binds us together

.. glossary::

    `Python <https://www.python.org/>`_

    `The Python Standard Library <https://docs.python.org/3/library/>`_ by the Python Software Foundation.


RomCom is enormously grateful to these authors for the breathtaking quality and scope of their work.
