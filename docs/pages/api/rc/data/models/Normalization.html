Normalization§

class Normalization(path, **tables)§

Bases: DataBase

Normalization of a Repo.

Parameters:

  • path (Store.Path)

  • tables (Table | PD.DataFrame)

Classes§

NamedTables

Must be overridden.

Protocols§

Indexed

self[key] accesses NamedTables by name or index/slice.

Len

len(self) counts the Table``s in ``self.

CreateProtocol

cls.create(path) is selective, preserving irrelevant items in path.

ReadProtocol

cls(path) reads from path.

UpdateProtocol

self(**tables) updates and writes ``NamedTables (self.meta(**updates) updates Meta.

DeleteProtocol

cls.delete(path) is selective, preserving irrelevant items in path.

CopyProtocol

cls.copy(src, dst) is selective, copying only relevant items in spath while preserving irrelevant items in dst.

StrReprProtocol

str(self) = str(self.path.name) and repr(self) = str(self.path).

Attributes§

options

Class attribute of the form NamedTables(**{names[i]: options[i], ...}).

Path

Class attribute aliasing Path | str, valid Types for specifying the path to a Store.

ext

Class attribute specifying the file extension terminating self.path.

Properties§

namedTables

The NamedTables currently in self.

meta

The Meta currently in self.

path

The Path to this Store, without cls.ext.

Methods§

(names[i], ...) of table names for this Tables class.
