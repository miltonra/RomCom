Glossary§

The User Guide follows Python convention by using | to denote logical OR.

RomCom is, for better or worse, laced with Python lingo.

axis§

A column in an experiment or Design. Each axis has a str head.

axisType§

A str which identifies the role of an axis in an experiment. See Axes and axisTypes.

categorical input§
discrete input§

An input variable whose value is one of a finite set of discrete values of Type int | str | bool. RomCom Types any such data as Category.

con§
conjoin§
unjoin§

The con character conjoins levels in a single head, or conjoins Category axes a single Category. It is defined as Table.con = │, the utf8 Box Drawing Light Vertical (U+2502) unlikely to occur in user data. Usually pronounced "given" (at least in the context of "conditional" probability), con means

word-forming element meaning "together, with"

[Online Etymology Dictionary]

from which we derive "conjunction", and "contingent" (on a condition).

CRUD§

Create, Read, Update, Delete. The conventional lifecycle for software objects stored on a filesystem.

decimal fraction§
float literal§

A string ending with % or a number containing a decimal point . or an exponent e or E.

Design§

A Type of Table with a validated schema designed to represent experiments. See designs.

dunder methods§

Special methods (also known as magic methods) whose names are surrounded by double underscores (dunders). The best known example is Python’s Class constructor __init__(self, **kwargs).

pl§

See ecosystem.

experiment§

The .csv you wish RomCom to analyse. RomCom sees any experiment as a Design. See Experiments.

folder§

directory.

head§

A row of str column headings.

kwargs§

Keyword arguments, an object of Type MetaData.

model§

An imprecise term for a Class which furnishes core functionality.

NaN§

Not a Number. A special floating-point value which is not equal to itself.

null§

Represents an absent value of any Type. None in Python.

pivoted§
unpivoted§

When a Table is pivoted on an axis, the unique values in that axis become head for a set of new axes which replace the original one. The reverse operation, unpivoting replaces a set of axes with one Category axis composed of the set head and one (Category or Float) axis composed of the group body. Pivoted tables are short and fat, unpivoted ones tall and thin.
